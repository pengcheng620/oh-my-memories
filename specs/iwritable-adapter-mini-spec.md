# IWritableAdapter — M2.A mini-spec

**Status**: Draft for M2.A implementation (`omem migrate --from <src> --to <tgt>`).

**Audience**: `@oh-my-memories/adapter-sdk`, `@oh-my-memories/core` migration orchestrator, Cat A IDE write implementations.

**Principles**:

1. **Composition over inheritance for the writable surface**: keep `IIdeAdapter` / `IMcpAdapter` / `ISaasAdapter` as *read contracts*. `IWritableAdapter` is a **separate interface** composed onto adapter classes where needed. This avoids polluting SaaS adapters with bogus `storageRoot`-style semantics and keeps `exactOptionalPropertyTypes`-safe option bags explicit.
2. **Management-first trust contract**: default to **refusing** writes when format support, probes, or conflict policy are ambiguous.
3. **Cross-platform**: only `node:fs/promises`, `node:path`, `crypto` (`createHash`), `AbortSignal`; no shelling out for file ops.
4. **Streaming stays read-side**: migration may *buffer* bounded batches for dedup, but must not load entire corpus into RAM; adapters stream **out** via async iteration for writes in logical chunks (`WriteBatch`).
5. **Spec alignment**: authoritative product rules for flags and manifest path come from **`specs/spec.md` §9**. Where `docs/MIGRATION.md` disagrees (e.g. `--on-conflict=both`), **update MIGRATION.md** to track this document + §9.

## 1. Interface design

### 1.1 Relationship to `IBaseAdapter`

- **Do not** add optional methods to `IBaseAdapter`.
- Concrete adapters continue to implement `IIdeAdapter` (or MCP/SaaS) for **read**.
- Adapters that support migration **also** implement `IWritableAdapter` in the same class (dual interface pattern) — e.g. `class ClaudeCodeAdapter implements IIdeAdapter, IWritableAdapter`.
- Runtime check: **`isWritableAdapter(a: unknown): a is IWritableAdapter`** guards migrate `--to`.

```ts
// packages/adapter-sdk/src/write.ts (new module; re-export from index.ts)

/** Declares which on-disk/host format build the writer targets. */
export interface AdapterFormatCapability {
  /** Same string family as scan / doctor (`claude-code/2026-05`, …). */
  readonly writeSchemaId: string;
  /**
   * Monotonic semver for *our* emitter. Bump when emitted JSON shape changes.
   * Distinct from host tool versioning — host may change silently; we only control our emitter.
   */
  readonly emitterVersion: `${number}.${number}.${number}`;
}

export type MigrateStrategy =
  | 'copy'
  | 'move'
  | 'link'; // M2.x — optional; M2.A may stub as unsupported

/** CLI `--on-conflict` → orchestrator-owned policy (see §3). */
export type ConflictPolicy = 'skip-on-conflict' | 'overwrite' | 'newest-wins';

export interface MigrateFilters {
  since?: Date;
  /** Resolved absolute path hint (tool-specific semantics in adapter notes). */
  projectPath?: string;
  sessionId?: string;
}

/**
 * Exactly one of dryRun modes. Default migration command omits mode = dry-run.
 * exactOptionalPropertyTypes: callers must omit `simulate`, not pass undefined.
 */
export type MigrateMode =
  | { readonly kind: 'dry-run' }
  | {
      readonly kind: 'apply';
      /**
       * When stdout is non-TTY OR `OMEM_NON_INTERACTIVE=1`, require this true
       * so scripts cannot accidentally `--apply`.
       */
      readonly approvedDestWrite: boolean;
    };

export interface MigrateContext {
  readonly signal?: AbortSignal;
  readonly filters: MigrateFilters;
  readonly strategy: MigrateStrategy;
  readonly conflictPolicy: ConflictPolicy;
  readonly mode: MigrateMode;
}

/** One logical append to a destination transcript file (or SaaS batch later). */
export interface WriteInstruction {
  /** Stable trace id for manifest (UUID v4 generated by orchestrator). */
  readonly operationId: string;
  readonly record: MemoryRecord;
  /** Provenance for manifest + rollback */
  readonly sourceAdapterId: string;
  readonly sourceFingerprint: string;
}

export interface WriteBatch {
  readonly instructions: readonly WriteInstruction[];
}

export interface WriteProbeResult {
  /** If false — migrate refuses `--apply`; dry-run still allowed. */
  readonly canWrite: boolean;
  readonly reason?: string;
  /** Host dir exists, quotas, writable test file succeeded, denylist clearance, etc. */
  readonly diagnostics?: Record<string, unknown>;
}

export interface PreparedWritePlan {
  /** Files the adapter intends to create or append-with-lock. */
  readonly targetPaths: readonly string[];
  /** Byte-size estimate per path (best-effort, for UX only). */
  readonly estimatedBytesByPath?: Readonly<Record<string, number>>;
}

export interface WriteBatchResultItem {
  readonly operationId: string;
  readonly status: 'written' | 'skipped' | 'failed';
  readonly reason?:
    | 'conflict-id'
    | 'conflict-fingerprint'
    | 'format-unsupported'
    | 'probe-failed'
    | 'filtered'
    | 'denylisted'
    | 'io-error'
    | 'dry-run';
  readonly destPath?: string;
}

export interface WriteBatchReceipt {
  readonly items: readonly WriteBatchResultItem[];
}

export interface MigrationReceipt {
  readonly sourceAdapterId: string;
  readonly destAdapterId: string;
  readonly startedAt: string; // ISO-8601
  readonly finishedAt: string;
  readonly mode: 'dry-run' | 'apply';
  readonly batches: readonly WriteBatchReceipt[];
  readonly probe: WriteProbeResult;
}

export interface IWritableAdapter {
  readonly writeCapability: AdapterFormatCapability;

  /**
   * Cheap pre-flight before any record work. MUST NOT mutate host data.
   * Called once per migrate invocation.
   */
  probeWrite(ctx: MigrateContext): Promise<WriteProbeResult>;

  /**
   * Confirm our emitter matches expectations for the *current* probe of on-disk samples.
   * Implementation may read≤N lines from existing transcripts (streaming), never full tree.
   */
  validateWritableFormat?(ctx: MigrateContext): Promise<{
    ok: boolean;
    reason?: string;
  }>;

  /**
   * Plan FS paths touched if apply proceeds — used for manifest + rollback + user preview.
   */
  planWrites(
    batch: WriteBatch,
    ctx: MigrateContext,
  ): Promise<PreparedWritePlan>;

  /** Execute one batch — idempotent where possible regarding operationIds. */
  writeBatch(batch: WriteBatch, ctx: MigrateContext): Promise<WriteBatchReceipt>;
}

/** Type guard for migrate target selection */
export function isWritableAdapter(v: unknown): v is IWritableAdapter {
  if (v === null || typeof v !== 'object') return false;
  const o = v as Record<string, unknown>;
  return (
    typeof o.writeCapability === 'object' &&
    o.writeCapability !== null &&
    typeof (o.writeCapability as AdapterFormatCapability).writeSchemaId === 'string' &&
    typeof (o.writeCapability as AdapterFormatCapability).emitterVersion === 'string' &&
    typeof o.probeWrite === 'function' &&
    typeof o.planWrites === 'function' &&
    typeof o.writeBatch === 'function'
  );
}
```

### 1.2 `MigrationReceipt` vs persisted **migration manifest**

- **`MigrationReceipt`** = in-memory / `--json` stdout summary for **one destination adapter invocation** (M2.A: single `--to`).
- Persisted **`MigrationManifest`** = JSON artifact on disk (§5) combining orchestrator envelope + flattened operations + rollback hints.

### 1.3 Declaring read-only vs write-capable

- **Read-only**: class does **not** implement `IWritableAdapter` / fails `isWritableAdapter`.
- **Write-capable**: implements `IWritableAdapter`; `probeWrite()` may still return `{ canWrite: false }` at runtime if environment unsafe.

`schemaVersionFor()` in `@oh-my-memories/core` remains **reader** versioning; **`writeCapability.writeSchemaId`** should track the reader family string **only when writer emits a format compatible with that reader contract**. If Claude Code bumps JSONL radically, bump `writeSchemaId` and refuse until shim lands.

## 2. Safety model

### 2.1 Versioned format detection

| Layer | Responsibility |
|-------|----------------|
| Reader (M1) | Tolerant parsing, `schemaVersionFor` marketing string |
| Writer (M2.A) | `writeCapability.emitterVersion` + **strict emitter** producing only known-good line shapes |

**Before any `--apply` write**:

1. `probeWrite()` — destination reachable, writable, not denylisted root.
2. `validateWritableFormat?.()` — sample **N = 2048** newline-terminated records from ≤4 newest eligible `.jsonl` under storage root (`readdir`, sort by `mtime`, cap files). Probe uses same streaming primitive as `@oh-my-memories/adapter-shared` **`streamJsonl`**. Classification:
   - **Empty corpus**: OK to create new transcripts (still require `--apply`).
   - **Mixed / unknown envelope**: **`ok: false`** — refuse `--apply`; dry-run shows reason.
   - **Recognised host envelopes** (adapter-specific fingerprints): `ok: true`.

3. **`writeCapability.writeSchemaId`** must equal `'claude-code/2026-05' | 'cursor/2026-05' | 'codex/2026-04'` for M2.A (mirror `inventory.ts`). On mismatch vs `inventory` reader version → **migration refuses** pending human bump (forces code review).

**When Claude Code JSONL schema drifts**:

- Writers **never** blindly emit into files that fail validation.
- Fallback: **`--staging-path=<dir>`** (orchestrator feature) dumps **canonical JSON Lines of `MemoryRecord` + metadata** outside host dirs — ships in M2.A as escape hatch *(optional CLI if time‑boxed)*; minimum is **hard refusal** without staging.

### 2.2 Dry-run default / apply API surface

| `omem migrate` flags | Behaviour |
|----------------------|-----------|
| *(no apply flag)* | **Dry-run**. Orchestrator consumes source `scan()`, runs destination `planWrites()` + simulated conflict resolver; manifest records `applied: false` for all write ops; optional `wouldApply: true` UX field in `--json` human layer only |
| `--apply` | Attempt real writes **only if** probes + validation pass |
| `--dry-run` | Explicit alias for default *(for scripts)* |

**Structured mode**: `--json` stdout wraps `MigrationManifest` envelope (§5).

### 2.3 Write-behind gate (explicit consent stacking)

Minimal **dual consent** for `--apply`:

1. CLI **`--apply`**
2. If **non-interactive** (`OMEM_NON_INTERACTIVE=1` or stdout not TTY): require **`--i-approve-dest-writes`** (name bikeshed OK; must exist as dedicated flag).

Optional **triple** belt for defense-in-depth *(recommended default in CI docs)*:

- Environment **`OMEM_I_APPROVE_DEST_WRITES=1`** must be present alongside `--apply` when `--non-interactive`.

**Rationale**: prevents `omem migrate ... --apply` in a blindly copied script from nuking transcripts.

### 2.4 Safe failure modes

| Condition | Behaviour |
|-----------|-----------|
| Format validation uncertain | Exit `1`; no writes |
| Destination file RO / EPERM | `OMEM-E04-PERM`; partial batches roll back via manifest |
| Mid-write crash | Next run: operationIds in manifest + temp files — user runs `--rollback` |
| Corrupt JSONL at dest | Do not repair host files; refuse writes touching that file; surface `doctor`-style hint |

**Backup** (M2.A **must**): immediately before mutating an existing destination file, copy to **`${OMEM_HOME}/migrations/backup/<manifestId>/<relative-path>.bak`** using `fs.copyFile` (same volume). Log path in manifest.

## 3. Conflict strategies

### 3.1 Authority & split of responsibility

| Component | Owns |
|-----------|------|
| **Orchestrator (`core`)** | Policy interpretation, fingerprinting, ordering, choosing which `WriteInstruction`s reach adapter |
| **Adapter** | Native identity for *destination* records, efficient existence checks, physical write |

### 3.2 Policies

| Policy | Rule |
|--------|------|
| **`skip-on-conflict` (default)** | If dest already has same **dedup key** (§3.3) with **equal fingerprint** → skip silently. If same key, **different** fingerprint → skip + manifest `reason: 'conflict-id'` (spec §9 naming). |
| **`overwrite`** | Replace destination payload for that key (adapter implements replace semantics; for append-only JSONL this means **rewrite file** with patch — **M2.A complexity**; MVP: only for destinations where replace is O(append) or implement **“append correction line”** forbidden — **refuse overwrite for CC JSONL in M2.A** unless full file rewrite behind backup is implemented). **Concrete default**: `overwrite` **supported only for Cursor & Codex** in M2.A; **Claude Code → refuse with error** OR require full-session rewrite flag `--rewrite-cc-session` (**deferred**) — autonomous pick: **`overwrite` disabled for Claude Code targets in M2.A** (`probeWrite` advertisement). |
| **`newest-wins`** | Compare `MemoryRecord.timestamp` (UTC ms). Winner overwrites loser **only where overwrite allowed** per target rules; else skip |

**Alignment note**: eng verdict `merge` / `prefix-source` ship **after** M2.A unless trivial; track as M2.B. Spec `prefix-source` maps to injecting metadata prefix into `text` — avoid silently mutating semantic content without `--apply` preview.

### 3.3 Dedup keys

Define in orchestrator (**not** trusting `record.id` across adapters):

```
fingerprint(record) =
  SHA-256( UTF-8( normalizeMarkdown(record.text) ) | '\0'
         | isoUTC(record.timestamp) | '\0'
         | record.role ?? '' | '\0'
         | record.sessionId ?? '' )  → hex lowercase
```

Normalize: trim trailing spaces, unify `\r\n→\n`; **do not** collapse inner whitespace beyond single-pass NBSP normalization.

**Destination collision key**:

- **`stableKey = `${record.source}:${record.id}``** for bookkeeping in manifest **only**.
- **Logical equality**: fingerprint match.
- **ID collision**: if destination adapter assigns **new IDs** on write (Cursor lines), collisions detected through **existing dest scan** hashed into a capped in-memory LRU / on-disk RocksDB-lite **not M2.A** — M2.A: load **fingerprints of destination** via **streaming re-scan** of affected sessions planned in `planWrites`; cap sessions via filters; spill not needed if filters tight; document memory warning.

Implementation guidance: orchestrator caches **fingerprints seen** **per destination session file** during `planWrites` **after** deterministic sort of incoming batch.

Serena collisions N/A read-only target.

## 5. Per-adapter write notes (M2.A)

### 5.1 Claude Code (`claude-code`)

| Topic | Detail |
|-------|--------|
| **Read format** | JSONL `{ type, uuid, sessionId?, timestamp, message:{role,content}, isMeta? }`, types `user`/`assistant` only |
| **Write target(s)** | Existing project folder under `${storageRoot}/<projectSlug>/`; **prefer creating new `.jsonl`** named `omem-import-<YYYYMMDD>-<shortid>.jsonl` **instead of mutating Anthropic originals** *(default)* — minimizes host corruption risk |
| **Format-version detection** | Sample existing files for envelope match; ours emit **exact Claude Code-compatible** lines (**reuse parser types**) |
| **Break risk** | Malformed UUID / missing `timestamp` crashes CC parser → **emitter integration test against fixture round-trip** |
| **Rollback** | Delete created import file OR restore `.bak` if appended |
| **`overwrite`** | **Not supported M2.A** |

### 5.2 Cursor (`cursor`)

| Topic | Detail |
|-------|--------|
| **Read schema** | Top-level `role`; id synthetic `sessionId#lineIndex`; timestamp=file mtime |
| **Write** | Append Cursor-native JSON objects to **`agent-transcripts/<newSession>/<newSession>.jsonl`** (session id generated v4 UUID; map `sessionId` metadata field in `MemoryRecord.metadata` as `legacySession`) |
| **Format detection** | Verify first `{` parses & has `.message.role` or top-level parity with fixture |
| **`overwrite`** | If dest fingerprint exists → rewrite last line (**avoid**) — MVP skip only |
| **Rollback** | Delete new session dirs |

### 5.3 Codex (`codex`)

| Topic | Detail |
|-------|--------|
| **Read schema** | `response_item` + `payload.message` lines with ISO timestamps |
| **Write** | Append under dated path **`sessions/<YYYY>/<MM>/<DD>/omem-import-<id>.jsonl`** mirroring rollout layout (**do not splice into rollout-*.jsonl**) |
| **Format detection** | Validate first line `{ timestamp, type }` passes existing parser subset |
| **Break risk** | Codex CLI rapid schema drift → **strict emitterVersion** + refusal |
| **Rollback** | Remove import file |

### 5.4 Serena (`serena`)

**Read-only in M2.A.** Markdown frontmatter + body round-trip warrants its own **`IWritableSerenaAdapter` mini-spec** (frontmatter escaping, hashing, multi-byte).

## 6. Test strategy

### 6.1 Mandatory tests per writable adapter (`packages/adapters/<id>/tests/`)

1. **`probeWrite` denies** when storage root absent or RO.
2. **`validateWritableFormat` fails** on fixture with **foreign / future** envelope (simulate unknown `type:"system_reset"` takeover).
3. **`writeBatch` dry-run** yields `status: skipped`/`reason: dry-run` without touching filesystem (use `tmpdir` watcher).
4. **`writeBatch` in apply mode** appends readable lines; subsequent **native `scan()`** on the same adapter picks up authored records (golden counts).
5. **Corrupted destination pre-state**: adapter **must refuse** mutation (manifest shows `probe-failed` / `format-unsupported`).

### 6.2 Testing “host tool format changed” without breaking installs

| Technique | Detail |
|-----------|--------|
| **Fixture subpoenas** | Versioned dirs `tests/fixtures/claude-code/cc-2026-05/`, future `cc-2027-fake/` synthetic breaking file — writer unit tests refuse |
| Record-replay emitter | Serializer functions pure — snapshot tests comparing JSON Lines |
| **Contract tests gated on env** optional `RECORD_HOST_FIXTURES=1` on dev machine only — CI never mounts real `~/.claude` |

### 6.3 Core orchestrator integration tests (`packages/core/tests/`)

3 scenarios:

1. CC → Cursor skip policy with duplicate fingerprints.
2. Non-interactive `--apply` without approval flag → **`OMEM-E25-MIGRATE-NO-APPROVE`**.
3. Manifest JSON schema snapshot stable.

## 10. CLI surface (`omem migrate`) — M2.A contract

SYNOPSIS (align with `docs/CLI.md` when implemented):

```text
omem migrate --from <adapterId> --to <adapterId>
           [--since <duration>] [--project <absPath>] [--session <id>]
           [--strategy copy|move|link]
           [--on-conflict skip-on-conflict|overwrite|newest-wins]
           [--dry-run] [--apply]
           [--i-approve-dest-writes]
           [--also-write-cwd-manifest]
           [--json] [--verbose] [--non-interactive] [--no-color]
```

| Flag | Default | Notes |
|------|---------|-------|
| `--from` | *required* | Source adapter id (`claude-code`, `cursor`, `codex`; `serena` allowed as source when project context configured) |
| `--to` | *required* | Must satisfy `isWritableAdapter` or exit `OMEM-E22-MIGRATE-NO-WRITER` |
| `--strategy` | `copy` | `move` deletes source **after** successful apply (manifest records deletions). `link` unsupported M2.A → `OMEM-E01-USAGE` |
| `--on-conflict` | `skip-on-conflict` | Maps to `ConflictPolicy` (`§1.1`) |
| `--apply` | off | Without it, `MigrateContext.mode = { kind: 'dry-run' }` |
| `--i-approve-dest-writes` | off | Required when `mode.kind==='apply'` **and** `(non-interactive OR OMEM_NON_INTERACTIVE)` |
| `--since` / `--project` / `--session` | — | Feed `MigrateFilters`; adapters may ignore unsupported combos with warning `OMEM-W01-FLAG` analogue `OMEM-W02-MIGRATE-FILTER-IGNORED` |
| `--json` | off | stdout = single `MigrationManifest` document on success |

Exit codes: reuse `CLI.md` — migration apply partial success may use `5` **only** when some operations failed but manifest written; hard probe failure → `1`.

Environment (extend `CLI.md` §Environment):

| Variable | Effect |
|----------|--------|
| `OMEM_I_APPROVE_DEST_WRITES` | When `1`, satisfies approve requirement in CI **in place of** `--i-approve-dest-writes` (still need `--apply`) |

## 11. Orchestrator algorithm (normative pseudocode)

Bounded memory: **batch size** default 500 `WriteInstruction`s; flush each batch to `writeBatch`.

```
function migrate(cmd):
  src = resolveAdapter(cmd.from)
  dst = resolveAdapter(cmd.to)
  assert isWritableAdapter(dst)

  ctx = buildMigrateContext(cmd)
  probe = await dst.probeWrite(ctx)
  if !probe.canWrite && cmd.apply:
     throw E23 or E04 depending on reason

  vf = dst.validateWritableFormat?.(ctx)
  if vf && !vf.ok && cmd.apply:
     throw E23

  // Build destination fingerprint index for planned sessions only
  fingerMap = await streamingScanDestFingerprints(dst, ctx.filters)

  receipts = []
  batch = []
  for await (rec of filteredScan(src, ctx)):
     fp = fingerprint(rec)
     stableKey = `${rec.source}:${rec.id}`
     decision = resolveConflict(fingerMap, rec, fp, ctx.conflictPolicy, dst.writeRules)
     if decision == SKIP:
        manifest.push(skipOp(...))
        continue
     batch.push({ operationId: uuid(), record: rec, sourceAdapterId: src.id, sourceFingerprint: fp })
     if batch.length >= 500:
        receipts.push(await runBatch(dst, batch, ctx, cmd))
        batch = []

  if batch.length:
     receipts.push(await runBatch(dst, batch, ctx, cmd))

  manifest = buildManifest(receipts, probe, backups...)
  writeManifestFile(manifestPath, manifest)
  optionallyCopyCwdManifest(cmd, manifest)
```

`runBatch`:

```
async function runBatch(dst, instructions, ctx, cmd):
  wb = { instructions }
  plan = await dst.planWrites(wb, ctx)
  recordBackupsForMutatedPaths(plan.targetPaths) // only on apply, before write
  return await dst.writeBatch(wb, ctx)
```

## 13. Dry-run manifest variant

When `dryRun: true`, **`backups` is empty**, every `write` operation uses `op: "would-write"` *(or `write` with `applied: false`* — pick one in implementation; **prefer** `op: "simulate-write"` for grep clarity). `summary.written` counts **would** writes. Rollback subcommand rejects dry-run manifests.

## 14. `MemoryRecord.metadata` keys reserved for migration

| Key | Value | Set by |
|-----|-------|--------|
| `omem.migration.originalSource` | string adapter id | orchestrator |
| `omem.migration.originalStableKey` | `<source>:<id>` | orchestrator |
| `omem.migration.importedAt` | ISO timestamp | writer on apply |
| `omem.migration.emitterVersion` | semver string | writer |

Adapters **must not** persist these into host JSON if the host rejects unknown fields — in that case strip before serializing line (CC may be strict; Cursor/Codex tolerant). If stripping required, keep keys only in manifest operations.

## 15. Threat model (short)

| Risk | Mitigation |
|------|------------|
| Silent data loss | `skip-on-conflict` default; backups before append to existing files |
| Host tool parse crash on our lines | Validator + golden round-trip tests |
| Accidental scripted apply | `--i-approve-dest-writes` / env gating under non-interactive |
| Path traversal in `--project` | Resolve + `path.relative` containment check vs adapter storage root |
| Denylisted secrets copied | Reuse `packages/cli/src/safety/denylist.ts` on **source paths** before read; destination writes under import dirs only |
