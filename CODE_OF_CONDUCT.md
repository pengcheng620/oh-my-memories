# Code of Conduct

We follow the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:
- Be kind, professional, and respectful.
- Disagree about ideas, not about people.
- Harassment, discrimination, and personal attacks are not tolerated.

Report violations to the repo maintainer (see `package.json` author field).
